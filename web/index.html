FM-1 Emulator

Boots an FM-1 firmware package headless, in your browser. The file stays on your computer.

GuestIdle 

    

    
It is an interpreter, so it runs far slower than the real instrument:
       expect minutes to reach the home screen.

  


  

    Built from the emulator's source
    (GPL-2.0-or-later, on QEMU). Firmware is not included.
